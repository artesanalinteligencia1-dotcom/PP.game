# Bitácora — NASA Space Apps Challenge 2026 (equipo Paulet Delta-V)

Lo que hicimos durante la hackathon (14–16 de noviembre de 2026) para la versión de concurso **Paulet: Andes to Orbit**
(reto *Space Mission Design Game*). El juego entregado vive en el repo público
`artesanalinteligencia1-dotcom/paulet-spaceapps-2026` (carpeta `game/`), publicado en https://paulet-spaceapps-2026.vercel.app.
Estos archivos salieron de ese repo en la limpieza final para dejarlo solo con el juego.

| Archivo o carpeta | Qué es |
|---|---|
| `HANDOFF.md` | **Entrada corta:** estado, dónde está cada cosa, pendientes y qué sección del completo leer |
| `HANDOFF_COMPLETO.md` | Memoria completa de la hackathon: fechas, reglas, decisiones, lo hecho y lo pendiente, paso a paso |
| `README-repo-hackathon.md` | El README del repo del concurso antes de la limpieza |
| `docs/SUBMISSION.md` | Texto de la página del proyecto (nombre, resumen, uso de IA, datos de NASA) |
| `docs/storytelling.md` | La historia: Goicochea, Kuntur, la promesa de Paulet, el gancho |
| `docs/act-videos.md`, `docs/mission-videos.md` | Guiones de las películas de actos y misiones |
| `docs/gemini-manual.md`, `docs/gemini-prompts.md` | Prompts y manual para las imágenes y clips generados con Gemini |
| `docs/tutoriales/`, `docs/screenshots/` | Tutoriales y capturas de trabajo |
| `media/video-kit/` | Kit de video (HyperFrames, voces Kokoro, `tools/publish.py`) |
| `media/act-videos/`, `media/mission-videos/` | Proyectos de las 16 películas (escenas, voces, imágenes, clips) |
| `media/characters/` | Hoja de personajes |
| `game/` | Notas internas que estaban dentro del juego (HANDOFF, PROGRESS, DECISIONS, PLAYBOOK, pruebas de video, prototipos) |

Música: canciones generadas en local con ACE-Step 1.5 (letras en `C:\Paulet\soundtrack\SONGS.md` y `SONGS2.md`, en la PC del dueño).

"Paulet: A 130-Year Promise" es la versión que seguirá después de la hackathon.
