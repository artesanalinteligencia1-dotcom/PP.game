# Translation glossary (English → Spanish)

Spanish variant: **neutral Latin American**, addressing the player as **tú** ("Elige", "Pulsa"), Peruvian-friendly
(inversionistas, computadora, celular). Numbers keep the game's own format; units stay SI (m/s, kg, W, km).
Keep untranslated: Δv, delta-v, TRL, LEO, GEO, GTO, SSO, L1, L2, CR3BP, Mbps, `{placeholders}`, the game name
(Paulet: Andes to Orbit) and rocket/spacecraft names (Paulet-1, L-1, M-2, H-3, R-2, R-3).
